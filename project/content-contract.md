# 内容与证据合同

## 来源映射

本框架使用 Martin 第二版的 Part、Chapter、Appendix 标题和起始页作为导航索引。起始页来自教材目录。框架不复制章节正文、习题或原图。

## 状态

- `未开始`：只有导航或空槽位。
- `进行中`：已有实质内容，但来源、推导、可视化或验证尚未闭合。
- `已完成`：当前定义的章节验收项已通过；不自动表示所有科学陈述获得独立验证。

## 科学表达

需要影响可信度时，区分：

- 【来源记录】：教材、论文、正式输出直接报告的内容；
- 【来源主张】：作者基于结果提出的解释；
- 【推断连接】：网站编写者基于现有证据做出的连接；
- 【已独立验证】：由独立方法或实现按明确标准完成的有限验证；
- 【未知/待验证】：证据不足。

## 可视化验收

每个可视化必须能回答一个明确问题，并提供：输入、输出、单位、模型或数据来源、默认值、适用范围、无效区域和不能支持的更强结论。
