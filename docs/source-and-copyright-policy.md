# Source and Copyright Policy

## 1. 目的

本项目借助教材和论文建立学习顺序，但网站内容必须是可公开审阅的原创解释、自制推导、自制图和合法可再分发的数据。来源定位用于核验和继续阅读，不构成复制许可。

## 2. 允许进入仓库的内容

- 书名、作者、版本、章节标题、节标题、页码范围和稳定书目标识；
- 对来源内容的原创概括与批判性说明；
- 独立完成的推导、示意图、交互模型和练习；
- 许可允许再分发或由本项目自行产生的小型数据；
- 指向出版社、DOI、arXiv 或官方文档的引用信息。

## 3. 不允许进入仓库的内容

- 教材或论文 PDF；
- 扫描页、页面截图或对原页面版式的重制；
- 大段逐字转录、连续翻译或可替代原作的章节内容；
- 未获许可的教材图表、题目集、答案或出版社附属材料；
- 仅作裁剪、换色、描边或重新排版的原图；
- 许可不明的网络图片、代码或数据；
- POTCAR 正文、商业软件内容、许可证材料和其他受限文件。

## 4. 教材使用方式

Martin 第 2 版用于建立电子结构理论的主干顺序；Sholl–Steckel 用于补充实践问题、收敛性和计算经验。两者均只作为外部阅读与核验来源：

1. 页面先记录来源和定位；
2. 网站正文以原创语言重新组织；
3. 公式属于通用科学表达时仍需解释符号、前提和推导连接；
4. 图形优先由模型或公开数据重新生成，并明确与来源图的关系；
5. 来源没有支持的解释不得假装来自教材。

## 5. 引用与事实边界

- 来源直接报告的数据或结果标为来源记录；
- 作者对结果的解释标为来源主张；
- 网站跨来源形成的解释标为推断连接；
- 独立复算或实现只有满足预先声明标准时才标为已独立验证。

多个来源重复同一主张、普通查看、文件存在或同一方法重复运行，不自动构成独立验证。

## 6. 自制可视化

每个可视化应在页面或数据元信息中说明：

- 是教学模型、解析结果还是实际计算数据；
- 输入参数、单位、参考零点和采样方式；
- 图形是否经过归一化、展宽、插值或降采样；
- 验收方法和已知限制。

不得使用视觉相似性暗示与教材图、实验图或真实材料结果等价。

## 7. 发现问题时

发现疑似侵权、许可不明或来源丢失的内容时：

1. 停止继续传播或部署；
2. 在独立分支中隔离或移除问题内容；
3. 保留文件路径、commit 和问题说明，不复制受限正文到 Issue；
4. 通过 PR 审查修复；
5. 对已发布内容检查部署缓存和派生文件。
