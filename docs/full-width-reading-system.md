# Full-width reading system

The reading shell is route-aware and shared through Starlight overrides. It does not require 56 MDX files to copy wrapper imports.

| Mode | Intended use | Width contract |
| --- | --- | --- |
| Parallel | Chinese–English comparison | up to 88rem; two bounded columns on wide screens |
| Focus | one-language or sequential reading | up to 54rem; margin space remains available |
| Atlas | maps, comparisons and wide figures | up to 88rem; prose itself is not stretched without bound |

At 72rem and above, the site uses left navigation, a flexible center canvas, and a 12–15rem semantic TOC. Below 64rem, bilingual columns stack and the semantic contents enter the document as a disclosure. At 390px the page is single-column; formulas and tables scroll locally.

Language and width choices are keyboard-operable and stored locally. No-JavaScript defaults to the complete bilingual Parallel view. Print restores both languages and removes display controls.
