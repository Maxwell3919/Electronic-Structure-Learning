# Future Home Experience

## Purpose

The homepage should introduce the project as an exploration space for electronic-structure knowledge rather than a traditional course landing page.

## Talos Interactive Guide

A future homepage may include Talos, the tuxedo cow cat mascot, as an interactive visual guide.

Talos should:

- help users discover the structure of the atlas;
- provide navigation cues;
- make the homepage approachable;
- connect visual exploration with scientific content.

Talos should not replace explanations or become a decorative element without purpose.

## Homepage Structure

Possible future sections:

```text
Home
├── Talos interactive introduction
├── What is electronic structure?
├── Explore Theory
├── Explore Methods
├── Explore Computational Tools
└── Find References
```

This document records a future design direction only. No implementation is required at this stage.
