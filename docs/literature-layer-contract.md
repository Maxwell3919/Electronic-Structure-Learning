# Literature-layer contract

Martin remains the textbook baseline. Later sources may extend, challenge, update, or contextualize that baseline, but never silently overwrite it.

The static data layer separates bibliography (`registry`), topics, reading workflow, claim assessment, and discussions. A citation does not prove a claim; `source-reported`, multi-source support, controversy, supersession, open status, and `not-assessed` remain distinct. Independent validation requires evidence beyond ordinary reading or repeated source claims.

This phase starts with empty registries. It does not fetch external content, embed PDFs, generate abstracts, infer conclusions from titles, or add a backend. Future entries require verified identifiers, source access and license status, related units, evidence role, reading state, and review date.
