每个单元从统一的目录骨架开始：

```text
来源与页码
  -> 目录级分节
  -> 学习定位
  -> 物理对象与符号
  -> 公式及其前提
  -> 原创可视化或数据实验
  -> 数值收敛与方法边界
  -> 练习与复盘
```
