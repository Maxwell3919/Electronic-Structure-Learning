每个学习单元按以下顺序组织：

```text
问题与学习目标
  -> 概念和物理对象
  -> 公式与前提
  -> 可调的简化模型
  -> 真实 DFT 数据示例
  -> 收敛性与适用边界
  -> 练习与复盘
```
