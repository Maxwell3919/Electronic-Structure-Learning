---
title: "Learning Map"
description: "从具体知识点通向电子结构理论的依赖关系图。"
---

Learning Map 属于 Theory。它描述概念之间的依赖关系，不规定唯一阅读顺序。

地图应细化到具体知识点。例如：

```text
晶格矢量
→ 晶格与晶体结构
→ 对称性
→ 倒空间
→ 布里渊区
→ Bloch 定理
→ 能带
```

另一条路径可能从向量空间和算符出发，经特征值问题、Schrödinger 方程和多电子问题到达 Kohn–Sham 方程。不同路径可以合流，也可以在中途分叉。

最终实现应支持多个入口、节点间交叉链接和来源说明。当前页面只固定这一信息模型，不预先生成未经审查的大型知识图。
