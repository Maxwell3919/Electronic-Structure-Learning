Reference 不是链接收藏夹。每项资源都应说明它解决什么问题、适合什么阶段、为什么值得推荐，以及它对应 Theory、Methods 或 Computational Tools 中的哪些内容。

## 范围

- 书籍
- 学习网站与课程
- 软件官方文档
- 数据库与在线服务
- 可视化资源
- 公式、术语与必要索引
