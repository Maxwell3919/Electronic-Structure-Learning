输入文件、输出文件、快速验收命令和常见错误必须放在对应软件或程序页面中。例如，Quantum ESPRESSO 的 `pw.x` 页面讨论其输入、输出和检查命令；这些内容不作为脱离环境的通用命令表维护。

快速验收只能支持命令所检查的有限状态。程序正常结束、电子迭代收敛、目标物理量收敛和科学结论成立必须分别判断。
