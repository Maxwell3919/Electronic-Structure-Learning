<h2 id="calculation-connection">与实际计算的连接 | Connection to Practical Calculations</h2>

<BilingualSection titleZh="从 Bloch 数据到可审计模型" titleEn="From Bloch data to an auditable model" eyebrow="Workflow">
  <div className="bilingual-section__zh">

Wannier 工作流应把下列对象逐层保存，而不是只保留最终 Hamiltonian：

1. **上游电子结构**：结构、赝势或全电子方法、功能、SOC/磁性、能量截断、SCF、coarse k mesh 和 band 数；
2. **目标问题**：要重现的能量范围、bands、Fermi surface 或 matrix elements；
3. **候选空间**：outer window、每个 k 的候选态数、trial projections 与 projection rank；
4. **固定维子空间**：Wannier 数、inner/frozen constraints、projector smoothness 与对窗口/初值的敏感性；
5. **gauge/localization**：centres、individual/total spreads、gradient、对称性、spinor convention 与局域极小值；
6. **实空间表示**：$H_{mn}(\mathbf R)$、overlap 或其他算符 matrix elements、距离 convention 和尾部衰减；
7. **独立验证**：未参与拟合的 dense k mesh、full target region、max/RMS band errors、projector distance、Fermi surface 与目标 matrix elements；
8. **应用层验收**：transport、Berry、optics、EPC、interaction parameters 等 observable 的独立收敛。

只有第 7–8 层覆盖了目标结论，才能把“计算生成了 Wannier functions”升级为“该 reduced model 对声明任务可靠”。

  </div>
  <div className="bilingual-section__en" lang="en">

A Wannier workflow should preserve each of the following objects rather than only the final Hamiltonian:

1. **Upstream electronic structure**: structure, pseudopotential or all-electron method, functional, SOC/magnetism, cutoff, SCF, coarse k mesh, and band count;
2. **Target question**: energy range, bands, Fermi surface, or matrix elements to reproduce;
3. **Candidate space**: outer window, candidate-state count at every k point, trial projections, and projection rank;
4. **Fixed-rank subspace**: Wannier count, inner/frozen constraints, projector smoothness, and sensitivity to windows and initialization;
5. **Gauge/localization**: centres, individual and total spreads, gradient, symmetry, spinor convention, and local-minimum sensitivity;
6. **Real-space representation**: $H_{mn}(\mathbf R)$, overlap or other operator matrix elements, distance convention, and tail decay;
7. **Independent validation**: a dense mesh not used for fitting, the full target region, maximum/RMS band errors, projector distance, Fermi surface, and target matrix elements;
8. **Application-level acceptance**: independent convergence of transport, Berry, optical, EPC, or interaction observables.

Only when stages 7 and 8 cover the target conclusion can “Wannier functions were generated” be promoted to “the reduced model is reliable for the declared task.”

  </div>
</BilingualSection>

<h2 id="common-misjudgments">常见误判 | Consequential Misjudgments</h2>

<div className="chapter23-misjudgments">
  <ol>
    <li><strong>“程序正常结束，所以模型可靠。”</strong> 正常结束只说明程序路径完成；subspace、窗口和 observable 仍需验证。</li>
    <li><strong>“spread 小，所以轨道具有唯一化学意义。”</strong> 同一 subspace 可有多个局域 gauges；最小值还可能受对称约束和初值影响。</li>
    <li><strong>“投影是 d 轨道，所以模型只含 d character。”</strong> 投影后的 Wannier functions 可包含配体 tails；需要 quantitative projector/orbital analysis。</li>
    <li><strong>“一条高对称路径吻合，因此 full-BZ 插值完成。”</strong> 未检查区域可存在 pocket、crossing 和局部误差。</li>
    <li><strong>“能带吻合，因此 Berry、optical 或 EPC 也吻合。”</strong> 这些 observable 依赖额外 matrix elements 和 gauge-covariant derivatives。</li>
    <li><strong>“outer window 越大越好。”</strong> 更大候选空间会改变 optimization、条件数和模型 character；需看 fidelity 与稳定性。</li>
    <li><strong>“nonorthogonal functions 更短，所以更准确。”</strong> 还需 overlap condition、dual basis 和 reconstruction/truncation error。</li>
    <li><strong>“hybrid centre 穿过晶胞边界就是拓扑态。”</strong> centre branch 本来 modulo lattice；拓扑需要完整 manifold 与 invariant。</li>
    <li><strong>“一个 Wannier Hamiltonian 可用于所有任务。”</strong> 每个 operator 与 observable 都有独立插值和收敛契约。</li>
  </ol>
</div>

<h2 id="exercises">原创练习 | Original Exercises</h2>

<div className="chapter23-exercises">
  <ol>
    <li><strong>Fourier 对偶。</strong> 从 $N_k$ 点离散变换推导逆变换、晶格平移关系和 Wannier 正交性。</li>
    <li><strong>gauge 平移。</strong> 对单 band 相位 $e^{imk}$，证明 Wannier 中心平移 $m$ 个晶胞而 band energy 和 projector 不变。</li>
    <li><strong>复合带旋转。</strong> 对两个中心相距 $d$ 的局域轨道作实幺正旋转，求各中心、spread 和 projector，解释哪些量 gauge invariant。</li>
    <li><strong>projection rank。</strong> 构造一个 $2\times2$ projection matrix，其最小奇异值随 k 在一点趋零；说明 Löwdin 正交化如何变得病态。</li>
    <li><strong>spread 分解。</strong> 从 $1=P+Q$ 推导 $\Omega_I$ 与 $\widetilde\Omega$，证明两项非负并指出 gauge 作用在哪一项。</li>
    <li><strong>离散 branch。</strong> 对一维 overlap product 加整数 gauge winding，比较 principal 与 unwrapped centre；设计连续参数下的 branch-tracking 算法。</li>
    <li><strong>非正交基。</strong> 给定 $A$，计算 $S=A^\dagger A$、dual basis 和 projector；展示忽略 $S^{-1}$ 如何破坏电子数。</li>
    <li><strong>outer window。</strong> 对 avoided crossing 模型扫描窗口，计算 trial-orbital fidelity，并找出无法由后续 localization 修复的区域。</li>
    <li><strong>downfolding。</strong> 对两能级 $P/Q$ 模型写出 $H_{\rm eff}(E)$，比较静态近似在远离和接近 Q 态时的误差。</li>
    <li><strong>hopping 截断。</strong> 对指数衰减 $t_R$，推导 band error 的上界并验证更长 decay length 需要更大 cutoff。</li>
    <li><strong>验证矩阵。</strong> 为 band、Fermi surface、velocity、Berry curvature、optical 和 EPC 分别列出最低独立验证对象。</li>
    <li><strong>拓扑边界。</strong> 解释为什么一组 hybrid-centre principal values 不能单独确定 winding，并列出所需 bulk/symmetry/branch 证据。</li>
  </ol>
</div>
