## 从原子生成到实际 DFT 计算 | From Atomic Generation to Practical DFT

<BilingualSection titleZh="文件身份先于数值参数" titleEn="Data-set identity precedes numerical parameters">
  <div class="bilingual-section__zh">

实际计算首先要确认赝势或 PAW 数据集的可复现身份，而不是先猜截断能。最低记录包括：元素、文件哈希或稳定版本、生成器及版本、交换—关联泛函、价电子组态、冻结芯/semicore 划分、NLCC、scalar-relativistic 或 fully relativistic 处理、局域通道、投影子数目、增广半径和来源许可。文件名可能编码部分信息，但不能替代文件元数据和来源记录。

同一计算中的元素数据应在 XC 和相对论层级上兼容。混用不同 XC 生成的数据会改变离子算符与自洽电子项之间的分区；非相对论和 fully relativistic 文件混用会使 SOC 通道不一致。兼容性是方法前提，不是通过提高 cutoff 能修复的离散误差。

  </div>
  <div class="bilingual-section__en" lang="en">

A practical calculation begins by identifying the pseudopotential or PAW data set reproducibly, not by guessing a cutoff. Minimum records include element, file hash or stable version, generator and version, exchange–correlation functional, valence configuration, frozen-core or semicore partition, nonlinear core correction, scalar- or fully-relativistic treatment, local channel, projector count, augmentation radii, source, and license. A filename may encode some of this information but cannot replace file metadata and provenance.

Element data used in one calculation should be compatible in XC and relativistic level. Mixing data generated with different XC functionals changes the partition between the ionic operator and self-consistent electronic terms. Mixing nonrelativistic and fully relativistic data gives inconsistent SOC channels. Compatibility is a methodological prerequisite and cannot be repaired by increasing the numerical cutoff.

  </div>
</BilingualSection>

<div class="table-wrap">

| Record | Example field, not a universal value | Why it matters |
|---|---|---|
| Source identity | library/release + stable file hash | Reconstructs the exact data set. |
| Generator | code and version | Defines construction equations and serialization. |
| XC | LDA, PBE, another declared functional | Must match the electronic calculation unless a justified protocol says otherwise. |
| Valence | explicit shells and occupations | Controls bonding space and electron count. |
| Semicore | included/frozen shells | Changes transferability, cost and response. |
| Relativity | nonrelativistic, scalar, fully relativistic | Determines scalar shifts and SOC channels. |
| Core correction | none or declared partial-core data | Changes XC in the core–valence overlap region. |
| Formal family | NCPP, USPP or PAW | Determines overlap, density and force expressions. |
| Suggested cutoffs | wavefunction and, where relevant, density/augmentation | Starting hints only. |
| Actual convergence | target observable versus all relevant cutoffs | Establishes numerical sufficiency for this calculation. |

</div>

<BilingualSection titleZh="截断能验收针对 observable" titleEn="Cutoff acceptance is observable-specific">
  <div class="bilingual-section__zh">

平面波展开截断的是轨道表示；USPP/PAW 还可能需要更高的密度或增广网格截断。总能对截断看似平坦，不保证力、应力、声子、介电响应或电子—声子矩阵元平坦。收敛测试必须固定其他数值参数，逐步增加相关截断，并以当前任务 observable 的变化作为判据。

Sholl–Steckel 提醒，在能量差中比较多个体系时，应使用一致的截断能，尤其当不同元素默认值不同。该规则减少基组不一致带来的系统误差，但只有结构和误差机制足够相似时才可能发生部分抵消；一致 cutoff 不能替代每个体系的收敛检查。

  </div>
  <div class="bilingual-section__en" lang="en">

A plane-wave cutoff truncates the orbital representation; USPP and PAW calculations can additionally require a higher density or augmentation-grid cutoff. A flat total-energy curve does not guarantee flat forces, stress, phonons, dielectric response, or electron–phonon matrix elements. A convergence test holds other numerical parameters fixed, increases every relevant cutoff, and judges changes in the observable required by the present task.

Sholl–Steckel emphasizes the use of a consistent cutoff when energy differences compare several systems, especially when element defaults differ. This reduces systematic errors from inconsistent bases, but partial cancellation is plausible only when structures and error mechanisms are sufficiently similar. A common cutoff does not replace convergence of each system.

  </div>
</BilingualSection>

```text
pseudopotential identity and compatibility checked
  -> reference atom and channel metadata inspected
  -> ghost/logarithmic-derivative evidence checked
  -> wavefunction and density/augmentation cutoffs converged
  -> SCF convergence demonstrated
  -> atomic/molecular/crystalline transferability evidence reviewed
  -> target force/stress/phonon/response observable converged
  -> cross-data-set or all-electron comparison where scientific risk requires it
```

## 常见误判 | Common Misjudgments

<div class="table-wrap">

| Misjudgment | Correction |
|---|---|
| “外区波函数匹配，所以所有性质相同。” | Matching is tied to declared channels, reference energies and operator assumptions; core-sensitive and higher-energy properties need additional information. |
| “Norm conserving means exact.” | It fixes specified reference and first-order response conditions, while frozen-core, XC and transferability errors remain. |
| “较软的势质量更高。” | Softness is a basis-cost property; accuracy and transferability require separate tests. |
| “库推荐 cutoff 就是最终 cutoff。” | A recommendation is a starting point; the target observable defines the accepted cutoff. |
| “PAW 是普通赝势的另一种名称。” | PAW is an explicit all-electron reconstruction transformation with auxiliary states and one-centre corrections, though practical implementations share projector machinery with USPP. |
| “fully relativistic 只影响能带后处理。” | Relativistic channel generation changes the core-region scattering operator used throughout SCF and response calculations. |
| “SCF 能收敛说明没有 ghost state。” | A ghost state can be a legitimate eigenstate of the pseudo-Hamiltonian and still allow numerical convergence. |
| “同一元素的不同文件可以混用。” | XC, valence partition, relativity, core correction and provenance must be compatible across the entire calculation. |

</div>

## 原创练习 | Original Exercises

1. **相移与截面。** 从部分波散射振幅出发，完成 Legendre 正交积分，证明单一 $l$ 通道对总截面的贡献为 $4\pi(2l+1)\sin^2\delta_l/k^2$。说明 $\delta_l\to\delta_l+\pi$ 为什么不改变截面。

2. **匹配半径。** 给定相同外区势和相同 $D_l(E,r_c)$，用二阶 ODE 唯一性说明两条外区径向函数只差整体常数。再指出为什么归一化需要额外条件。

3. **OPW 范数。** 对一个正交芯态集合推导 $\langle\chi_q|\chi_q\rangle=1-\sum_c|\langle\phi_c|q\rangle|^2$，并解释为什么这导致广义重叠矩阵。

4. **排斥算符。** 证明价态能量高于全部芯态能量时，Phillips–Kleinman 型投影项是半正定的。构造一个能量依赖性会破坏 transferability 的例子。

5. **范数响应。** 重新推导 Wronskian 恒等式，并检查采用 Rydberg 原子单位时公共因子如何改变。写出仍保持不变的物理比较结论。

6. **径向反演。** 选一个满足 $u\sim r^{l+1}$ 的无节点解析赝函数，反演 $V_l^{scr}$。检查 $r\to0$ 时离心项与 $u''/u$ 的奇异项是否抵消。

7. **NLCC。** 对局域形式 $V_{xc}[n]\propto n^{1/3}$，比较 $V_{xc}[n_v+n_c]$ 与 $V_{xc}[n_v]+V_{xc}[n_c]$，说明芯—价重叠时为什么不能线性拆分。

8. **Hardness。** 使用 Fourier-tail 教学模型，证明固定容差下芯半径减半使动能截断代理增加四倍。说明为何该比例不能直接用于真实赝势。

9. **KB 投影子。** 从 $|\beta_l\rangle=\Delta V_l|\phi_l\rangle$ 出发，证明单投影子算符在参考态上的作用与半局域通道一致。列出该证明没有覆盖的两个谱性质。

10. **多投影子。** 对两个参考态构造 $2\times2$ 的 $B$ 矩阵。研究两态逐渐线性相关时 $B^{-1}$ 和数值误差如何变化。

11. **USPP 总电荷。** 从 generalized normalization 与 augmentation density 出发，积分密度并证明电子数等于占据数总和。

12. **PAW 算符。** 将 $\mathcal T$ 代入 $\widetilde A=\mathcal T^\dagger A\mathcal T$，识别 smooth、AE one-centre 和 pseudo one-centre 三类贡献。说明 augmentation spheres 重叠时需要额外处理的原因。

13. **验证设计。** 为一个含 3d 过渡金属和轻元素的声子计算设计最小验证矩阵。必须分别给出 pseudopotential identity、semicore、relativity、wavefunction/density cutoff、k/q 网格、力和频率判据。

14. **证据审查。** 某论文只写“使用 PBE PAW，截断 500 eV，SCF 收敛”。列出复现和判断赝势可靠性仍缺少的最小信息，并区分“无法复现”与“科学上可能不可靠”。
