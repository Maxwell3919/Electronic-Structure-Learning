<h2 id="notation">对象、坐标与证据边界 | Objects, Coordinates, and Evidence Boundaries</h2>

<dl class="chapter-terms">
  <div>
    <dt>Bravais lattice | Bravais 晶格</dt>
    <dd>所有整数平移 $\mathbf T(\mathbf n)=\sum_i n_i\mathbf a_i$ 的集合；每个 lattice point 的无限环境等价。<span lang="en">The set of all integer translations $\mathbf T(\mathbf n)=\sum_i n_i\mathbf a_i$; every lattice point has the same infinite environment.</span></dd>
  </div>
  <div>
    <dt>primitive vectors | 原始平移矢量</dt>
    <dd>生成平移群的一组线性无关最小向量。它们不唯一，但 determinant 的绝对值给出相同 primitive-cell volume。<span lang="en">A linearly independent generating set of the translation group. It is not unique, but the determinant magnitude gives the same primitive-cell volume.</span></dd>
  </div>
  <div>
    <dt>primitive cell | 原胞</dt>
    <dd>平移后恰好铺满空间且平均含一个 lattice point 的区域。parallelepiped 和 Wigner–Seitz cell 都可为 primitive cell。<span lang="en">A region that tiles space by translations and contains one lattice point on average. A primitive parallelepiped or Wigner–Seitz cell are both valid.</span></dd>
  </div>
  <div>
    <dt>conventional cell | 惯用胞</dt>
    <dd>为显示点群或实验轴而选的非最小晶胞；可含多个 primitive cells。<span lang="en">A nonminimal cell chosen to expose point symmetry or experimental axes and possibly containing several primitive cells.</span></dd>
  </div>
  <div>
    <dt>basis / motif | 基元</dt>
    <dd>附着在每个 Bravais lattice point 的有限原子集合 $\{\tau_s\}$。crystal = lattice + basis。<span lang="en">The finite set of atomic positions $\{\tau_s\}$ attached to every Bravais lattice point. Crystal = lattice + basis.</span></dd>
  </div>
  <div>
    <dt>fractional/lattice coordinates | 分数坐标</dt>
    <dd>$\tau_s=\sum_i\tau^L_{si}\mathbf a_i$；坐标分量是 primitive-vector coefficients，不是 Cartesian length components。<span lang="en">$\tau_s=\sum_i\tau^L_{si}\mathbf a_i$; the components are primitive-vector coefficients, not Cartesian length components.</span></dd>
  </div>
  <div>
    <dt>Wigner–Seitz cell</dt>
    <dd>比任何其他 lattice point 更靠近选定原点的点集；它是 real-space translation lattice 的第一 Voronoi cell。<span lang="en">The set of points closer to a chosen lattice point than to any other; the first Voronoi cell of the real-space lattice.</span></dd>
  </div>
  <div>
    <dt>reciprocal lattice | 倒格子</dt>
    <dd>满足 $e^{i\mathbf G\cdot\mathbf T}=1$ 对所有 Bravais translations 成立的向量集合；primitive reciprocal vectors 满足 $\mathbf a_i\cdot\mathbf b_j=2\pi\delta_{ij}$。<span lang="en">The set of vectors satisfying $e^{i\mathbf G\cdot\mathbf T}=1$ for every Bravais translation; primitive reciprocal vectors obey $\mathbf a_i\cdot\mathbf b_j=2\pi\delta_{ij}$.</span></dd>
  </div>
  <div>
    <dt>first Brillouin zone | 第一 Brillouin 区</dt>
    <dd>reciprocal lattice 的 Wigner–Seitz cell。它是常用但不是唯一的 reciprocal primitive cell。<span lang="en">The Wigner–Seitz cell of the reciprocal lattice. It is the preferred but not unique reciprocal primitive cell.</span></dd>
  </div>
  <div>
    <dt>crystal momentum $\mathbf k$</dt>
    <dd>平移群表象的标签，定义 modulo $\mathbf G$。它不是一般等于机械动量 $\langle\hat{\mathbf p}\rangle$。<span lang="en">The representation label of the translation group, defined modulo $\mathbf G$. It is not generally equal to mechanical momentum.</span></dd>
  </div>
  <div>
    <dt>band index $n$</dt>
    <dd>固定 $\mathbf k$ block 中离散本征态的标签；不同 band 可因 symmetry 相交、hybridize 或交换 orbital character。<span lang="en">A label for discrete eigenstates within a fixed $\mathbf k$ block. Bands may cross by symmetry, hybridize, or exchange orbital character.</span></dd>
  </div>
  <div>
    <dt>irreducible Brillouin zone | 不可约 Brillouin 区</dt>
    <dd>在 point/time-reversal symmetry 下生成完整 BZ 的最小 k-region；weights 必须恢复完整 integral。<span lang="en">A minimal k region generating the full BZ under point and time-reversal symmetries; weights must reconstruct the complete integral.</span></dd>
  </div>
</dl>

  <div class="bilingual-section__zh">
    <ul>
      <li>CIF/POSCAR 的 cell choice 不自动是 primitive cell，也不唯一；</li>
      <li>相同 Cartesian 原子图可因不同 translation group 产生不同 Bravais lattice 描述；</li>
      <li>symmetry finder 的空间群依赖 tolerance、occupancy、磁矩和原子身份；</li>
      <li>high-symmetry path 只展示选定一维线，不覆盖 full-BZ extrema、pockets 或 topology；</li>
      <li>数据库 k mesh、band labels 或 DOS 不能替代当前结构/方法/数值参数下的收敛。</li>
    </ul>
  </div>
  <div class="bilingual-section__en" lang="en">
    <ul>
      <li>a CIF or POSCAR cell is not automatically primitive and is not unique;</li>
      <li>the same Cartesian atomic picture can have different Bravais descriptions if the translation group changes;</li>
      <li>a symmetry-finder space group depends on tolerances, occupancies, magnetic moments, and atomic identities;</li>
      <li>a high-symmetry path samples selected one-dimensional lines and cannot establish full-BZ extrema, pockets, or topology;</li>
      <li>database k meshes, band labels, and DOS do not replace convergence for the present structure, method, and numerical settings.</li>
    </ul>
  </div>
